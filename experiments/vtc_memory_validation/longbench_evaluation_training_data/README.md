# LongBench Evaluation Training Data

This directory contains training data used for compressor experiments that are evaluated on LongBench. LongBench evaluation itself still uses `longbench_official/data/*.jsonl`.

## Files

| File | Purpose | Clean for LongBench eval? |
|---|---|---|
| `longbench_sourceqa_train_balanced.json` | Task-adapted LongBench-source QA training data | Yes |
| `longmemeval_qa_train.json` | LongMemEval-derived QA training data used for cross-domain LongBench evaluation experiments | Yes for LongBench eval, but leaky for LongMemEval eval |

## `longbench_sourceqa_train_balanced.json`

Generated from source-task train splits corresponding to LongBench QA tasks. MultiFieldQA is not included because LongBench MultiFieldQA is test-only / author-annotated and has no official train split.

Generation command:

```bash
python experiments/vtc_memory_validation/longbench_official/build_sourceqa_train.py \
  --out experiments/vtc_memory_validation/longbench_evaluation_training_data/longbench_sourceqa_train_balanced.json \
  --max_qas_per_source 2000 \
  --max_chars 24000 \
  --seed 0
```

Source breakdown:

| Source | Dataset / file | Split | QA count |
|---|---|---:|---:|
| NarrativeQA | `deepmind/narrativeqa` | `train` | 2000 |
| Qasper | `qasper-train-dev-v0.3.tgz` / `qasper-train-v0.3.json` | `train` | 2000 |
| HotpotQA | `hotpotqa/hotpot_qa`, config `distractor` | `train` | 2000 |
| 2WikiMultiHopQA | `voidful/2WikiMultihopQA` | `train` | 2000 |
| MuSiQue | `dgslibisey/MuSiQue`, answerable only | `train` | 2000 |

Output size: 10000 QA triples. The number of passages is not balanced because some sources attach multiple QA pairs to one passage.

## `longmemeval_qa_train.json`

Generated by converting LongMemEval oracle QA rows into the `[{passage, qas:[{q,a}]}]` format consumed by `softtoken/train.py --qa_train`.

Generation command:

```bash
python experiments/vtc_memory_validation/memory_mix/generate_memory_mix.py convert-longmemeval \
  --longmemeval experiments/vtc_memory_validation/data/longmemeval_oracle.json \
  --output experiments/vtc_memory_validation/longbench_evaluation_training_data/longmemeval_qa_train.json
```

This file is useful for cross-domain experiments that train on LongMemEval QA and evaluate on LongBench. It should not be used as clean training data for LongMemEval evaluation, because it is derived from the LongMemEval oracle/eval set.
